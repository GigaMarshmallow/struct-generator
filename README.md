# Struct Generator

**Автор:** Цырлина Мария Игоревна, группа M3115  
**IDE:** Visual Studio Code  
**Язык:** TypeScript

Расширение для VS Code, которое генерирует C++ структуры из текстового описания.

## Что делает

По клику на кнопку в статус-баре открывается форма. Пользователь вводит описание структуры в компактном формате одной строкой:

    Person: string name, int age, string email

Расширение парсит строку, проверяет корректность данных и генерирует готовый C++ код вида:

    struct Person {
        std::string name;
        int age;
        std::string email;
    };

Результат можно скопировать в буфер обмена одной кнопкой.

## Возможности

- Кнопка быстрого доступа в статус-баре VS Code.
- Ввод описания структуры одной строкой.
- Парсинг имени структуры и списка полей.
- Валидация:
  - проверка имени структуры (идентификатор C++);
  - проверка каждого поля;
  - проверка на дубликаты имён полей;
  - понятные сообщения об ошибках.
- Автоматическая генерация C++ кода с правильными отступами.
- Копирование результата в буфер обмена.
- Поддержка типов с пробелами (unsigned int, long long).

## Формат ввода

    ИмяСтруктуры: тип1 имя1, тип2 имя2, тип3 имя3

Примеры:

- Person: string name, int age, string email
- Point: int x, int y
- Student: unsigned int id, std::string fullName, double gpa

## Установка

Для установки расширения выполните следующие действия:
1. Загрузите файл расширения (`.vsix`) из раздела релизов соответствующего репозитория.
2. Откройте среду разработки Visual Studio Code и перейдите в панель управления расширениями, нажав комбинацию клавиш `Ctrl+Shift+X`.
3. В правом верхнем углу панели нажмите на значок с дополнительными параметрами (три точки) и выберите пункт **Install from VSIX...** (Установить из VSIX).
4. В открывшемся диалоговом окне укажите путь к загруженному файлу и подтвердите установку.


## Использование
1. Откройте любую рабочую директорию (папку) в Visual Studio Code.
2. В нижней части окна (в статус-баре) нажмите на кнопку "Create Struct".
3. В открывшейся панели введите описание структуры в требуемом формате.
4. Нажмите кнопку "Обработать" для получения сгенерированного кода.
